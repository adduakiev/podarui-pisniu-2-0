# Подаруй пісню — локальна тестова система

Реалізовано: сайт, форма з серверним збереженням у SQLite, захищена адмінка одного користувача, замовлення/нотатки/статуси, наступна дія, ручні платежі з історією та захистом повторного збереження, дедлайн через 48 годин від повного брифу, завантаження публічних пісень і скриншотів, контроль дозволу та публікації, перегляд відгуків як сторіс.

## Запуск

Node.js 24 або новіший (SQLite через вбудований node:sqlite). `npm install`, створити `.env.local` за `.env.example`, `npm run dev`. Локальна адреса http://127.0.0.1:3000, адмінка /admin. Пароль задається через ADMIN_PASSWORD у приватному .env.local. Не додавайте його до коду або Git. Локальні API/browser-перевірки отримують пароль через змінну середовища ADMIN_PASSWORD. Сесія HttpOnly на 8 годин.

`npm run typecheck`, `npm test`, `npm run build`. База та медіа у `data/`, не в публічному каталозі. Не видаляйте їх для збереження результатів.

## Межі готовності

Це локальна версія, не продакшн. SQLite не призначена для файлової системи Vercel; сервер навмисно відмовляється використовувати її в Vercel. Перед розгортанням потрібні Supabase, власний вхід/MFA, захист форми та ліміти на рівні інфраструктури, резервування й перевірка відновлення. API провайдера оплат, автоматичні повідомлення, зберігання приватних версій конкретного замовлення ще не підключені. Оплати вручну; відправка готової пісні поза системою. Архів клієнтів не імпортовано. Використовуйте лише вигадані дані.

Сторіс першої версії: кожен скриншот — окрема кругла картка; групування кількох кадрів під власною обкладинкою, зміна порядку та редагування матеріалів — наступний крок. Завантаження до 20 МБ, публікація лише після позначки дозволу; приватні дані на скриншоті слід приховати до завантаження.

Лого типографічне та кольори взяті з поточного сайту, hero та favicon — оригінальні матеріали. Юридичні сторінки — копії вихідних документів, ще потребують узгодження редакції для нової системи. Немає персонального демо. Початкові приклади й відгуки не вигадані — порожні до завантаження.
