# Подаруй пісню 2.0

Приватний репозиторій розробки. Застосунок у song-system/, матеріали команди у office-start/.

Це тестове середовище, не production. База, клієнтські дані, завантажені файли, токени, .env.local та локальні архіви не включені. Відгуки й приклади замінено явно вигаданими fixtures.

Для GitHub Codespaces використовуйте .devcontainer/devcontainer.json: Node.js 24, встановлення залежностей через npm ci, порт 3000 приватний. Докладні межі та налаштування: [CLOUD_SETUP.md](CLOUD_SETUP.md).
